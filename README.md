# Ukraine Cities

A small, responsive static webpage introducing three cities in Ukraine: Kyiv, Lviv, and Odesa. Visitors can use the navigation links to jump to each city's photo and description.

## Project contents

- `index.html` - page structure, styling, navigation, and city descriptions
- `images/kyiv.jpg` - Kyiv cityscape
- `images/lviv.jpg` - Lviv City Hall
- `images/odesa.jpg` - Odesa beach

## View the page

Open `index.html` in a web browser. The project uses only HTML and CSS, so no installation, build step, or server is required.
